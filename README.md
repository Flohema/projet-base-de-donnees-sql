# Projet de base de données – Plateforme de formation

## Description

Projet SQL réalisé dans le cadre d'un travail de conception et
d'exploitation d'une base de données pour une plateforme de formation.

L'objectif est de gérer les cours, utilisateurs, inscriptions,
sessions, examens, tentatives et rôles des utilisateurs.

## Technologies

- MySQL
- SQL
- Modélisation relationnelle
- Vertabelo

## Fonctionnalités

- Gestion des cours et de leurs parties
- Gestion des utilisateurs et des rôles
- Inscriptions aux cours
- Gestion des sessions
- Gestion des examens et tentatives
- Contraintes d'intégrité
- Triggers pour automatiser certaines règles métier
- Procédures stockées
- Requêtes SQL d'analyse

## Structure

- `database_create.sql` : création du schéma
- `database_constraints.sql` : contraintes, triggers et procédures
- `database_queries.sql` : requêtes SQL
- `database_data.sql` : données de test
